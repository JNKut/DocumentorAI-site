Install guide

Add your assistant to your website

It takes one line of code and about two minutes. You don't need a developer.

1. Get your line of code

When your assistant is ready we'll email you a line that looks like this, with your assistant's address in place of your-assistant-url:

<script src="https://your-assistant-url/widget.js"></script>

Paste it once so it loads on every page. The chat button appears in the bottom-right corner.

2. Paste it into your site

WordPress

  1. Install a header and footer code plugin, such as WPCode, from Plugins → Add New.
  2. Open the plugin's Header & Footer screen.
  3. Paste the line into the Footer box and save.

Shopify

  1. Go to Online Store → Themes, click ⋯ next to your live theme, and choose Edit code.
  2. Open layout/theme.liquid.
  3. Paste the line just above </body> and click Save.

Wix

  1. In your dashboard, go to Settings → Custom Code (under Advanced). Wix requires a premium plan with a connected domain for this.
  2. Click + Add Custom Code and paste the line.
  3. Choose All pages, Load code once, and Body - end, then Apply.

Squarespace

  1. Go to Settings → Advanced → Code Injection. Code Injection is only available on some Squarespace plans.
  2. Paste the line into the Footer box and save.

Webflow

  1. Open Site settings → Custom code.
  2. Paste the line into Footer code, save, and Publish your site. Custom code requires a paid site plan.

Any other website

Paste the line just before the closing </body> tag on every page, or in your site's shared footer template.

3. Check it

Open your published site in a new browser window. You should see the chat button in the bottom-right corner. Ask it a question about your business to make sure it's using your documents.

Options

To show the button in the bottom-left corner instead, add data-position:

<script src="https://your-assistant-url/widget.js" data-position="bottom-left"></script>
We can also lock your assistant so it only appears on your own domains. Email us the addresses of your sites and we'll set it up.

Not showing up?

  • Make sure you published or saved the change on your live site, then reload with a hard refresh (Ctrl+Shift+R, or Cmd+Shift+R on a Mac).
  • Check the line was pasted exactly as we sent it, with nothing missing at the start or end.
  • Some ad blockers hide chat widgets. Try a private window with extensions turned off.
  • Still stuck? Email jonahkutikov@gmail.com with your website address and we'll take a look.
